How EarthTrend Detective works

  1. Get the data: we download a monthly time series for your location directly from NASA (MERRA-2 / NASA POWER, 1981–present, or MODIS satellite greenness, 2000–present).
  2. Measure the change: we fit a trend line and report the rate of change per decade with a 95% confidence interval.
  3. Test significance: we run the Mann-Kendall test (corrected for autocorrelation), a regression t-test, and a change-point test, then explain the result in plain language.
  4. Compare places: the Trend Map shows how the same variable can rise in one region and fall in another.

🧪 Variable Scanner — which variables are trending here?

Tests 19 NASA variables (plus optional MODIS greenness) at the location chosen in Investigate. Because testing many variables at once raises the chance of a false alarm, p-values are corrected with the Benjamini–Hochberg false discovery rate (q-value). A variable is flagged only if q < 0.05.

Results

Click a row to open it in Investigate. Trend = Theil–Sen slope; p = modified Mann–Kendall; q = FDR-corrected p.

🗺️ Trend Map — where is it changing?

The same variable can trend one way in one region and the opposite way in another. This map runs the full trend test on every NASA POWER grid cell (0.5° × 0.625°) around your location.
